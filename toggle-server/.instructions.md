# AI Agent Instructions - toggle-server

## Mandatory rules
1. Toda mudança de comportamento deve vir com teste.
2. Execute `mvn clean verify` antes de concluir qualquer tarefa de código.
3. Nunca altere migrações Flyway já existentes em `src/main/resources/db/migration`.
4. Mantenha o formato de erro HTTP baseado em `ProblemDetail`.
5. Evite acoplamento cross-context (`toggle`, `client`, `delivery`) ao introduzir novo código.

## Coding guardrails
- Preferir mudanças pequenas e focadas.
- Preservar APIs públicas existentes salvo pedido explícito.
- Em queries potencialmente caras, evitar padrão N+1.
- Em código assíncrono, garantir configuração explícita de executor quando necessário.

## Test guidance
- Testes web: `@WebMvcTest` + mocks
- Regras de negócio: testes unitários com JUnit 5 e Mockito
- Para mudanças de persistência/eventos, priorizar inclusão de testes de integração em fases seguintes

## Definition of done
- Build, testes e gate de cobertura passando
- Documentação atualizada quando houver mudança de comportamento
- Sem warnings óbvios de qualidade introduzidos
