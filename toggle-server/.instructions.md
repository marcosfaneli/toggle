# AI Agent Instructions - toggle-server

## Mandatory Rules
1. Every behavior change must include a test.
2. Run `mvn clean verify` before completing any code task.
3. Never change existing Flyway migrations in `src/main/resources/db/migration`.
4. Keep the HTTP error format based on `ProblemDetail`.
5. Avoid cross-context coupling (`toggle`, `client`, `delivery`) when introducing new code.

## Coding Guardrails
- Prefer small, focused changes.
- Preserve existing public APIs unless explicitly requested otherwise.
- Avoid N+1 patterns in potentially expensive queries.
- Ensure explicit executor configuration for asynchronous code when required.

## Test Guidance
- Web tests: `@WebMvcTest` + mocks
- Business rules: unit tests with JUnit 5 and Mockito
- For persistence/event changes, prioritize integration tests in following phases

## Definition Of Done
- Build, tests, and coverage gate pass
- Documentation updated when behavior changes
- No obvious quality warnings introduced
